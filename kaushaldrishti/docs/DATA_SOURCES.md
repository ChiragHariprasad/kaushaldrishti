# Data Sources

## How to add real data

Place files in `data/incoming/`. The adapter system auto-detects file types and maps columns to the canonical schema. If a file is absent, the pipeline falls back to synthetic data for that source (clearly labelled `data_mode: synthetic`).

## Available Loaders

| Source | File format | Where to obtain | Adapter |
|--------|-------------|-----------------|---------|
| **PLFS** | Excel/CSV | [MOSPI](https://mospi.gov.in/plfs) — Periodic Labour Force Survey | `adapters/plfs.yaml` |
| **NCS** | CSV | [National Career Service](https://www.ncs.gov.in/) — vacancy extracts | `adapters/ncs.yaml` |
| **e-Shram** | CSV | [e-Shram Portal](https://eshram.gov.in/) — district x occupation aggregates | `adapters/eshram.yaml` |
| **NCO-2015** | CSV | [DGE&T](https://dge.gov.in/) — National Classification of Occupations | `adapters/nco.yaml` |
| **QP Mapping** | CSV | [NSDC](https://nsdcindia.org/) — Qualification Pack to NCO mapping | `adapters/qp.yaml` |
| **LGD Districts** | CSV | [LGD](https://lgdirectory.gov.in/) — Local Government Directory | `adapters/lgd.yaml` |

## Data Modes

Every record carries a `data_mode` label:

- `live` — Real-time API feed (future; not in pilot)
- `public_aggregate` — Official published aggregate statistics
- `partner` — Data shared by industry/training partners
- `synthetic` — Generated by the pipeline for demonstration; always labelled

## File Drop Instructions

1. Download the file from the source portal
2. Place it in `data/incoming/` without renaming
3. Run `make refresh` — the adapter system detects and processes it
4. Check `data/incoming/quarantine/` for any rejected records
