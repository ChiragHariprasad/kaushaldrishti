# Model Cards

This directory contains model cards for every model in the KaushalDrishti system.

Each model card documents:
- **Data**: training data sources, time range, data modes
- **Metrics**: performance on backtests vs baselines
- **Limitations**: known failure modes, edge cases
- **Intended use**: forecasting scope and advisory nature

*Model cards will be generated starting in M4 (Forecasting).*
