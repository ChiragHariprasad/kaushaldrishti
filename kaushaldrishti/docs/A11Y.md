## Implemented Features

*To be documented as screens are built in M7.*

### Planned

- [ ] Full keyboard navigation with visible focus indicators
- [ ] Skip links to main content
- [ ] Semantic landmarks (`<nav>`, `<main>`, `<aside>`, etc.)
- [ ] Proper heading hierarchy (single `<h1>` per page)
- [ ] ARIA labels for all charts and maps
- [ ] Text/table alternative for every chart
- [ ] Colour-blind-safe palette (no information by colour alone)
- [ ] Contrast ratio >= 4.5:1 for all text
- [ ] Text-size control (100–150%)
- [ ] `prefers-reduced-motion` support
- [ ] Low-bandwidth mode (no map, no animation, tables only)
- [ ] Indian digit grouping (lakh/crore) for en and hi locales
- [ ] Screen-reader-friendly language switcher
- [ ] Read-aloud for district brief (browser Speech API)
